Session Management & Timeout
Automatic logout kapag inactive (e.g., 15-30 mins)

Database Encryption
Ini-encrypt ang data sa database para hindi mabasa kahit ma-access ng unauthorized users.

Login Attempt Monitoring (correct spelling ng “Atempt”)
Tina-track ang failed/successful logins.
Pwede mag-lock account after multiple failed attempts (anti-brute force).

Database Backup
Regular backup para may recovery kapag may data loss o attack.

SQL Injection Protection & Input Validation
Pinipigilan ang malicious inputs sa forms.
Includes sanitization + prepared statements.

Security Questions (mas common kaysa “Security Questionare”)
Additional identity verification (e.g., password reset).

Trusted Devices / Device Verification
Kinikilala ang known devices.
Nagre-require ng confirmation kapag bagong device ang ginamit.
